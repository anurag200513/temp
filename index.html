Device Connectivity & Widget Setup

  1. Enable USB Debugging

    Go to your phone's Settings > About Phone and tap Build Number 7 times. Then go to System > Developer Options and toggle USB Debugging ON.

  2. Connect to PC

    Connect your phone to your PC via a USB cable. Make sure the USB mode is set to "File Transfer" or "MIDI".

  3. Allow USB Debugging Dialog

    Unlock your phone screen. A popup will ask: "Allow USB debugging?". Check "Always allow from this computer" and tap Allow.

  4. Start ThermaGuard Server

    Ensure the Python server script is running. It will automatically detect your phone using adb and stream live hardware temperatures!

Pro Tip: You can also connect wirelessly! Enable "Wireless Debugging" in Developer Options, and run adb connect <phone-ip>:<port> in your terminal.

Since standard mobile browsers cannot place web pages directly as widgets natively, follow these steps to place the live monitor directly on your Android home screen using a Web Widget container:

  1. Download a Web Widget App

    Go to the Google Play Store on your phone and install a free web widget app (e.g., Web Widget by lowlevel or Widgetizer).

  2. Connect to the Same Wi-Fi Network

    Ensure your phone and the monitoring PC are connected to the exact same Wi-Fi router network.

  3. Get your PC's IP Address

    Open a terminal on your PC and run ipconfig (Windows) or ifconfig (Linux/Mac) to find your local IP address (e.g., 192.168.1.104).

  4. Configure the Widget URL

    Add the widget element to your home screen. Open its settings and set the target source URL to:
    http://<your-pc-ip>:8000/widget.html

Seamless Look: The widget features a transparent background, matching colors, and real-time auto-updating via SSE, blending directly with your background launcher!
