# Contributing to ThermaGuard

Thank you for helping improve ThermaGuard.

## Local Development
1. Ensure Python 3.9+ and Android Platform Tools (`adb`) are available on `PATH`.
2. Start the local server with `python server.py`.
3. Open `http://localhost:8000` in your browser.

## Pull Request Guidelines
- Keep frontend and backend changes modular.
- Update documentation in `docs/` when adding endpoints or simulator presets.
